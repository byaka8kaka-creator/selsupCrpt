Ежедневное обновление токенов двух организаций

Включённые действия

Выключенный шаг пропускается в обоих проходах. Без шага 1 его статус не проверяется. Без шага 5 выполняется один проход для текущей организации. При одной кнопке токена и выключенном шаге 1 эта кнопка относится к шагу 2.

CSS-селекторы при изменении сайта

Пустые поля — поиск по тексту. Для шага 5 селектор должен содержать {organization} — название нужной организации. Каждый селектор должен находить один видимый элемент.

Браузер должен быть открыт. Нужны вход в SelSup и работающий CryptoPro. При автоматическом входе браузер временно показывает уведомление об отладке. Закройте DevTools вкладки SelSup на время входа. Выполняются только включённые действия и проверки. Результат остальных действий проверяйте на сайте.
