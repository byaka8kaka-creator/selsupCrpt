# SelSup CRPT — расширение Chromium

JavaScript-расширение Manifest V3 для Chromium и совместимых сборок, включая Chromium Ghost, если сборка поддерживает Manifest V3 и установку распакованных расширений. Сборка Ghost отдельно не проверялась.

## Установка

1. Скачайте репозиторий или архив расширения, распакуйте его.
2. Откройте `chrome://extensions`, включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**, выберите папку `extension` (ту, где находится `manifest.json`).
4. Откройте SelSup в том же профиле браузера, сохраните логин и пароль в менеджере паролей браузера и проверьте их автозаполнение на странице входа. Можно также заранее войти в аккаунт. Проверьте доступ к сертификату и CryptoPro. Если CryptoPro запрашивает разрешение или PIN, их нужно предоставить вручную. Для доверенного сайта используйте официальные настройки CryptoPro.
5. Откройте расширение через значок на панели или кнопку **Параметры** в списке расширений. Укажите точные названия двух организаций, время и паузу. Начальные названия взяты со скриншотов; их можно менять.
6. Сохраните настройки, проверьте **Запустить сейчас**, затем включите ежедневный запуск и снова сохраните.

Node.js, npm и сервер для использования расширения не нужны. Зависимости npm нужны только для разработки и тестов.

## Сценарий

Расширение открывает новую активную вкладку `https://selsup.ru/application/integration/crpt`, дожидается загрузки и выбирает первую организацию. При всех включённых действиях выполняет:

| Шаг | Действие |
| --- | --- |
| 1 | Верхняя кнопка «Получить токен» в разделе «Честный знак: Токен» |
| 1а | Дождаться статуса верхнего токена с датой в пределах ±5 минут от текущего времени |
| 1б | Открыть поле категории между нижним токеном и «Проверить СУЗ», выбрать «Корма для животных» и подтвердить выбор |
| 2 | Нижняя кнопка «Получить токен» в разделе «Токен» |
| 3 | «Проверить СУЗ» |
| 4 | «Сохранить» |
| 5 | Переключиться на вторую организацию |
| 1–4, включая 1а и 1б | Повторить действия для второй организации |
| 5 | Вернуться на первую организацию |

После каждого клика, включая открытие списка категории, выбор пункта и переключение организации, выдерживается пауза (по умолчанию 5 секунд). Ожидание появления и доступности каждого элемента — до 60 секунд по умолчанию. При отсутствии, неоднозначности или недоступности элемента выполнение прекращается с записью причины. Вкладка остаётся открытой для проверки.

## Выключение действий при изменении страницы

В настройках есть блок **«Включённые действия»**: отдельные переключатели шагов 1–5, выбора категории и проверки статуса верхнего токена. После изменения переключателей нажмите **«Сохранить настройки»**. Уже выполняющийся сценарий использует настройки, сохранённые при его запуске.

Если верхняя кнопка «Получить токен» исчезла, снимите галочку **«1. Верхний „Получить токен“»**. Расширение не будет ждать эту кнопку и проверять её статус. Единственная оставшаяся кнопка «Получить токен» будет считаться нижней (шаг 2); категория и остальные включённые действия выполняются для обеих организаций. Если кнопку вернут на сайт, шаг можно включить снова.

Выключенные действия пропускаются с записью в журнале. Их CSS-селекторы сохраняются, но не проверяются и не используются для поиска отключённого действия. Переключатель категории отключает и открытие списка, и выбор «Корма для животных». Проверка статуса доступна только при включённом шаге 1; выключение проверки сохраняет нажатие кнопки и паузу после него. Если выключить шаг 5, расширение выполняет один проход для текущей организации без выбора первой, переключения на вторую и возврата.

Поиск категории по умолчанию использует нижнюю кнопку токена и, при наличии, «Проверить СУЗ» как ориентиры. Если эти элементы исчезли, для включённого выбора категории может понадобиться отдельный CSS-селектор поля. При обновлении расширения старые настройки сохраняются, новые переключатели изначально включены.

Кнопки определяются по видимому тексту, две кнопки токена — по порядку в DOM. Скриншоты не дают DOM сайта, поэтому соответствие реальной странице необходимо проверить вручную. При изменении сайта задайте уникальные CSS-селекторы в дополнительных настройках. Для организации селектор должен включать `{organization}`, например `[data-org="{organization}"]`, если такой атрибут действительно есть на сайте. Расширение подставляет название и экранирует его для CSS. Не копируйте этот пример без проверки HTML страницы.

После шага 1 расширение проверяет именно верхнюю надпись `Токен успешно получен: ДД.ММ.ГГГГ ЧЧ:ММ:СС`. Статусы «Токен ЦРПТ» и «Токен СУЗ» не принимаются за верхний токен. Проверяются календарная дата и разница с текущим временем компьютера: не более пяти минут в любую сторону. Часы и часовой пояс компьютера должны соответствовать отображаемому времени SelSup. Также проверяется, что дата надписи изменилась после клика: прежняя свежая надпись не считается подтверждением. Исключение — получение токена в ту же секунду, что и клик, поскольку сайт показывает время с точностью до секунды. Если надпись не обновилась, не появилась или дата слишком старая/будущая, расширение ждёт до заданного таймаута, затем останавливается **до выбора категории и шага 2** с ошибкой в журнале.

При полной перезагрузке страницы после нажатия верхнего токена расширение продолжает проверку статуса по сохранённому состоянию, без повторного клика. Таймаут при перезагрузке не начинается заново. Обновление интерфейса без перезагрузки документа также поддерживается. При перезагрузке браузера весь запуск по-прежнему прекращается. Продолжение после полной перезагрузки на остальных шагах не реализовано: при потере связи с такой страницей сценарий остановится по контрольному таймауту.

Категория всегда устанавливается в **«Корма для животных»**, независимо от исходного выбора. Это происходит в обоих проходах после проверки верхнего токена и перед нажатием нижнего. Поддерживаются стандартный `select` и выпадающие элементы, в том числе Ant Design; автоматический поиск ограничен полем между нижним токеном и проверкой СУЗ. Если структура сайта отличается, задайте CSS-селекторы поля, пункта и статуса в дополнительных настройках. Открытие списка проверяется по появлению видимого меню; используется наведение, событие указателя, нажатие мыши, клик или клавиша ArrowDown, причём после успешного открытия остальные попытки прекращаются. Это предотвращает повторное закрытие меню. При отсутствии меню сценарий останавливается с сообщением «Список категории не открылся» за несколько секунд, не ожидая пункт в закрытом списке. После выбора расширение проверяет отображаемое значение поля. Если выбор не подтверждён, шаг 2 не выполняется.

**Журнал подтверждает статус верхнего токена и выбор категории, а для остальных действий — нажатия и ожидания.** Проверка успешного получения нижних токенов, сохранения на сервере и диалогов CryptoPro не реализована. Выбирайте паузу с запасом и проверяйте итоговые статусы на сайте. Не редактируйте страницу и не переключайте организацию вручную во время сценария.

## Автоматический вход

При загрузке расширение распознаёт форму авторизации по видимому полю пароля и обычной кнопке **«Войти»**. Перед нажатием доступной кнопки оно всегда выдерживает **3 секунды**, даже если значения полей или признаки автозаполнения уже видны JavaScript. Начало обязательной паузы записывается в журнале. Затем расширение нажимает кнопку один раз и ждёт загрузки включённых элементов страницы CRPT. **«Войти с Яндекс ID»** не нажимается. Если JavaScript не видит заполнение после паузы, одна попытка входа всё равно допускается: Chromium может показывать сохранённый пароль, скрывая его значение от скрипта. Причина такого нажатия также записывается в журнале.

Вход работает при форме на том же адресе CRPT, на отдельном адресе SelSup и при полной перезагрузке или смене интерфейса без перезагрузки. Если после входа открылась главная страница, расширение возвращается на URL CRPT и продолжает сценарий. Состояние входа сохраняется до навигации; общий таймаут не начинается заново при каждой загрузке. Автоматическая авторизация выполняется только в вкладке активного запуска; другие вкладки SelSup не затрагиваются.

Логин и пароль должны автозаполняться **самим браузером**. Расширение использует признаки заполнения без сохранения, копирования в сообщения или записи в журнал значений полей. Доступ к хранилищу паролей браузера не запрашивается. Значения, видимые JavaScript, не являются обязательным условием нажатия: даже при пустых полях допускается одна попытка входа после ожидания браузера. Если вход потребовал дополнительных действий или после одного нажатия форма осталась открыта, сценарий останавливается по общему таймауту. Повторных попыток отправить форму нет. Завершение входа подтверждается появлением включённых элементов CRPT, а не исчезновением кнопки «Войти».

## Расписание и журнал

- Время интерпретируется в часовом поясе компьютера с браузером. Следующий запуск виден в настройках.
- Браузер должен быть открыт, компьютер — бодрствовать. Расширение не запускает закрытый браузер и не будит компьютер; браузер может задержать alarm после сна. При перезапуске браузера следующий запуск назначается на ближайшее будущее выбранное время, пропущенный запуск не догоняется.
- Пересчёт расписания после изменения системного часового пояса: сохраните настройки ещё раз.
- Сценарии не выполняются параллельно. Плановый запуск допускается один раз за локальную календарную дату. Неудачный запуск не повторяется автоматически, чтобы не дублировать уже выполненные действия. Ручной повтор доступен после проверки журнала.
- **Остановить** прекращает дальнейшие действия; совершённые клики не отменяются. При потере связи с вкладкой блокировка снимается контрольным alarm примерно через 90–150 секунд. При перезапуске браузера прерванный запуск отмечается ошибкой.
- В `chrome.storage.local` сохраняются настройки и последние 1000 записей журнала. Журнал можно скачать в JSON или очистить. Очистка журнала не сбрасывает настройку расписания и защиту от повторного запуска за день.
- Расширение не читает значения токенов, сертификатов и паролей и не отправляет журнал на внешние серверы. Оно имеет доступ только к `https://selsup.ru/*`; действия выполняются на странице интеграции и, при необходимости, на форме входа SelSup в той же вкладке.

## Разработка и проверки

```sh
cd /workspace/selsupCrpt
npm ci --cache /tmp/selsup-npm --ignore-scripts --no-audit --no-fund
npm test
```

Нужны Node.js 24 и Chromium в `/usr/lib/chromium/chromium` (используется бинарник без обёртки Debian). Playwright управляет системным Chromium без загрузки отдельного браузера. `npm test` проверяет клики реальным браузером на HTML-фикстуре, автоматический вход, отсутствие автозаполнения, неудачную авторизацию, перенаправление после входа, полную перезагрузку после шага 1, старую и будущую дату, выбор категории, страницу без верхней кнопки и независимое отключение действий. Настройки и сохранение переключателей, а также расписание, журнал, блокировка, остановка и восстановление проверяются с тестовым API Chrome. Реальный аккаунт и CryptoPro не используются.

Полная проверка установленного расширения отдельно:

```sh
npm run test:e2e
```

Этот тест устанавливает расширение в отдельный временный профиль Chromium и проверяет service worker и интерфейс. **В текущей облачной среде он заблокирован системной политикой `ExtensionInstallBlocklist: ["*"]`: установленное расширение здесь не проверено.** Для этой проверки нужен Chromium без запрета установки расширений. Политики системного браузера тесты не изменяют. Использование самого расширения в Chromium Ghost с настоящим SelSup и CryptoPro требует ручной проверки после установки.

Создание архива:

```sh
npm run pack
```

Архив появится в `artifacts/selsup-crpt-extension.zip`. Распакуйте его перед установкой. После изменений исходников нажмите **Обновить** на карточке расширения в браузере.
